# Coffre DND et plugin partagé
Le plugin reste dans bryantoualy-del/Kentaro, branche fix/shared-companion-obsidian-importer. Le dossier Obsidian et les commandes gardent leur identifiant. Installer ensemble main.js, styles.css et manifest.json de la même version dans .obsidian/plugins/kentaro-session-importer. Le ZIP Kobe exige la version 1.5.

Avant la séance, choisir Kobe dans la préparation, rechercher et sélectionner jusqu’à vingt PNJ et ouvrir le Companion. Pendant la séance, capturer les faits dans Journal → Carnet de session. Marquer les présences ou associer les entrées. Les portraits locaux utilisent IndexedDB.

Télécharger le ZIP de la session active ou archivée. Dans le coffre DND, ouvrir l’importeur et vérifier la source, les nouveaux documents et chaque fait proposé. Les statuts restent à sélectionner. Les portraits existants sont conservés et le reçu de fin identifie le couple source/session. Le dossier historique des reçus reste 98 - Archives/Imports Kentaro/.
