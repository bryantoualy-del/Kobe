# Kobe

### Icône sur iPad et iPhone

Dans Safari, ouvrez Kobe, puis choisissez **Partager → Sur l’écran d’accueil**.
Si un ancien raccourci affiche toujours son ancienne icône, rechargez Kobe dans
Safari en ligne et ajoutez un nouveau raccourci. Si l’icône reste en cache,
exportez votre sauvegarde depuis le raccourci existant avant de le supprimer
et de le recréer. À la prochaine mise à jour de l’icône, incrémentez le
paramètre `v` des liens d’installation et régénérez le cache avec
`npm run offline:sync`.
